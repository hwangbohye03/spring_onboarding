# 실행 가이드

## 1. `.env` 파일 설정

스프링 부트 애플리케이션 등에서 사용할 DB 접속 정보를 `.env` 파일에 정의합니다.

```env
DB_URL=jdbc:mysql://localhost:<로컬 포트>/<데이터베이스명>
DB_USERNAME=<사용자 이름>
DB_PASSWORD=<비밀번호>
```


## 2. Docker 컨테이너 실행

### 컨테이너 실행 명령어
```bash
docker run --name mysql-todo \             # 컨테이너 이름 설정 및 실행
  -e MYSQL_ROOT_PASSWORD=<루트 비밀번호> \   # 환경변수 설정
  -e MYSQL_DATABASE=<데이터베이스 이름> \    
  -e MYSQL_USER=<사용자 이름> \             
  -e MYSQL_PASSWORD=<사용자 비밀번호> \      
  -p <로컬 설정 포트>:3306 \                 # 포트 포워딩 설정 (호스트 포트 : 컨테이너 포트)
  -v mysql-todo-data:/var/lib/mysql \      # 볼륨 바인딩 설정 (도커 볼륨 : 컨테이너 데이터 경로)
  -d mysql:8.0                             # 백그라운드 실행 및 이미지 버전 지정
```
### 주요 설정 및 옵션 설명
* **자동 이미지 다운로드 (Pull)**
    * 로컬에 `mysql:8.0` 이미지가 없으면 Docker 데몬이 Docker Hub에서 자동으로 다운로드(Pull)한 후 컨테이너를 실행함

* **포트 포워딩 (`-p 호스트포트:컨테이너포트`)**
    * 호스트(내 컴퓨터)의 지정 포트로 들어오는 요청을 컨테이너 내부의 `3306` 포트로 전달함
    * **효과:** 이미 로컬에서 `3306` 포트를 사용 중이더라도 `-p 3307:3306`처럼 호스트 포트만 변경하여 포트 충돌 없이 실행할 수 있음

* **볼륨 바인딩 (`-v 볼륨이름:컨테이너경로`)**
    * 컨테이너 내부 디렉토리와 호스트(또는 Docker 전용 볼륨) 저장소를 서로 연결(마운트)함
    * **필요성:** 컨테이너가 삭제되면 내부 데이터가 완전 소멸되는 휘발성 구조를 보완하기 위한 설정
    * **효과:** 실제 DB 데이터가 저장되는 컨테이너 경로(`/var/lib/mysql`)를 외부 저장소(`mysql-todo-data`)에 연결해 두면, 컨테이너를 삭제하고 재창조해도 데이터가 안전하게 보존됨

* **백그라운드 실행 (`-d`)**
    * 컨테이너를 터미널 세션과 분리하여 백그라운드(데몬) 상태로 실행함
    * **효과:** 실행 후 터미널 창을 닫더라도 컨테이너는 종료되지 않고 계속 동작함

### 컨테이너 실행 확인 명령어
```bash
docker ps
```
